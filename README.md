# ClockVibe — Site Completo

Interface web criada para praticar a construção de um site com identidade visual própria, navegação entre páginas e organização de conteúdo relacionado a relógios, planos e temas.

## Páginas

- `index.html` — Página inicial.
- `planos.html` — Apresentação de planos.
- `temas.html` — Opções de temas visuais.

## Tecnologias

| Tecnologia | Uso |
| --- | --- |
| HTML5 | Estrutura das páginas |
| CSS3 | Layout, cores e tipografia |

## Como visualizar

Clone o projeto e abra `index.html` no navegador:

```bash
git clone https://github.com/Raydev15/clockvibe-site-completo.git
cd clockvibe-site-completo
```

Para servir os arquivos localmente:

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000` no navegador.

## O que este projeto demonstra

O projeto demonstra a aplicação de hierarquia visual, consistência entre páginas, organização de estilos e criação de uma interface responsiva para uma proposta de produto digital.
